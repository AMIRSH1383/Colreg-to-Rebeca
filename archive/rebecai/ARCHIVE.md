# Historical RebecAI material

These files preserve the former manually written Legata/coordinator architecture.
Tests here are historical specifications, not an executable supported pipeline;
several referenced modules were already absent at the starting revision.
`legacy_baseline/Rule19`, `Rule22`, and `Rule23` contain COLREG-related baselines.
`Rule622`, `Ruleb11`, and `Ruleb12` contain Istanbul Strait/Legata article case
studies; retain their original identifiers and content. They are not additional
COLREG rule numbers. Baselines are comparison inputs, not authoritative ground truth.
The old schema is preserved here. Its previous active location now references the
current verification schema for compatibility. The original README and skill
instructions are retained unedited. See preservation.json for starting checksums.
